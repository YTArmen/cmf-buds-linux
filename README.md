# CMF Buds для Linux

Небольшая программа для настройки наушников **CMF Buds** на компьютере с Linux. Умеет то же, что приложение Nothing X на телефоне.

> Неофициальная программа. Не связана с Nothing Technology Limited. CMF и Nothing — их торговые марки.

## Что умеет

- **Заряд** левого и правого наушника и кейса. Показывает, если идёт зарядка.
- **Шумоподавление**: выключено, прозрачность или шумоподавление. Сила: сильное, среднее или слабое.
- **Эквалайзер**: готовые настройки звука.
- **Ultra Bass**: включение и уровень от 1 до 5.
- **Низкая задержка** для игр и видео.
- **Жесты**: что делают касания на каждом наушнике (двойное, тройное, удержание, двойное с удержанием).
- **Версия прошивки**.

Если сменить режим касанием наушника, программа сразу покажет новый режим. Если убрать наушники в кейс, программа подключится сама, когда вы их достанете.

### AirPods

Программа умеет работать и с **AirPods** (проверено на AirPods Pro 2). Если подключены и CMF Buds, и AirPods, сверху появятся вкладки.

- **Заряд** левого, правого наушника и кейса.
- **Шумоподавление**: выкл, шумоподавление, прозрачность, адаптивный режим.
- **Адаптация к разговору** и **шумоподавление с одним наушником**.
- **В ушах ли наушники**, и **пауза музыки**, когда вынимаете наушник.

> Apple и AirPods — торговые марки Apple Inc. Программа с Apple не связана.

Проверено на CMF Buds с прошивкой 1.0.5.050 (Ubuntu, GNOME). На других моделях CMF или Nothing может работать частично.

## Что нужно

- Linux с Bluetooth (BlueZ — он есть почти везде).
- Python 3.
- GTK 4 и **libadwaita 1.7 или новее**. Есть в Ubuntu 25.04 и новее, Fedora 42 и новее, Arch, Debian 13.

## Установка

### Шаг 1. Поставить библиотеки

Откройте терминал и выполните команду для своей системы.

**Ubuntu / Debian / Linux Mint:**
```bash
sudo apt install python3-gi gir1.2-gtk-4.0 gir1.2-adw-1 git
```

**Fedora:**
```bash
sudo dnf install python3-gobject gtk4 libadwaita git
```

**Arch / Manjaro:**
```bash
sudo pacman -S python-gobject gtk4 libadwaita git
```

Проверить, что всё на месте:
```bash
python3 -c "import gi; gi.require_version('Adw','1'); from gi.repository import Adw; print(Adw.get_major_version(), Adw.get_minor_version())"
```
Должно вывести `1 7` или больше (например `1 9`).

### Шаг 2. Подключить наушники к компьютеру

1. Откройте кейс и зажмите кнопку на кейсе на 2–3 секунды, пока не замигает индикатор.
2. На компьютере откройте **Настройки → Bluetooth** и выберите **CMF Buds**.
3. Подождите, пока появится надпись «Подключено».

Если наушники подключены к телефону, сначала отключите их там или выключите Bluetooth на телефоне.

### Шаг 3. Скачать и установить программу

```bash
git clone https://github.com/YTArmen/cmf-buds-linux.git
cd cmf-buds-linux
./install.sh
```

Установщик кладёт программу в `~/.local/share/cmf-buds` и добавляет значок в меню. Пароль администратора не нужен.

### Шаг 4. Запустить

Нажмите клавишу **Super** (со значком Windows), введите **CMF Buds** и кликните по значку.

Или из терминала:
```bash
python3 ~/.local/share/cmf-buds/cmf_buds.py
```

## Если что-то не работает

| Что видно | Что сделать |
|---|---|
| «CMF Buds не найдены» | Наушники не сопряжены с компьютером. Повторите шаг 2. |
| «Наушники не на связи» | Достаньте наушники из кейса и проверьте, что они подключены в настройках Bluetooth. |
| `Namespace Adw not available` или ошибка про `ToggleGroup` | libadwaita старше 1.7. Обновите систему или поставьте более новую версию дистрибутива. |
| Наушники переименованы | Укажите адрес вручную: `python3 ~/.local/share/cmf-buds/cmf_buds.py AA:BB:CC:DD:EE:FF`. Адрес видно в `bluetoothctl devices`. |

## Обновление и удаление

Обновить:
```bash
cd cmf-buds-linux && git pull && ./install.sh
```

Удалить:
```bash
rm -rf ~/.local/share/cmf-buds ~/.local/share/applications/cmf-buds.desktop
```

## Как это работает

Программа общается с наушниками так же, как приложение на телефоне: через Bluetooth RFCOMM, канал 15, по протоколу Nothing. Каждая команда — это пакет `55 60 01`, номер команды, длина, данные и контрольная сумма CRC16 (Modbus).

| Что | Чтение | Запись | Данные |
|---|---|---|---|
| Заряд | `C007` | — | число устройств, затем пары (устройство, %) ; 2 = левый, 3 = правый, 4 = кейс; бит `0x80` = заряжается |
| Шумоподавление | `C01E` | `F00F` | `[1, режим, 0]`: `05` выкл, `07` прозрачность, `01`/`02`/`03` сильное/среднее/слабое |
| Эквалайзер | `C01F` | `F010` | `[пресет, 0]` |
| Ultra Bass | `C04E` | `F051` | `[вкл, уровень × 2]` |
| Низкая задержка | `C041` | `F040` | `[1 вкл / 2 выкл, 0]` |
| Жесты | `C018` | `F003` | `[1, наушник, 1, жест, действие]` |
| Прошивка | `C042` | — | строка |

**Не до конца проверено.** Наушники принимают любой номер пресета и действия, поэтому названия пресетов эквалайзера и действий жестов могут не совпадать с телефоном. Если нашли расхождение, откройте issue.

## English (short)

Unofficial GTK4 app to control **CMF Buds** on Linux: battery, noise control (off / transparency / ANC with 3 levels), EQ presets, Ultra Bass, low-latency mode, tap gestures. Not affiliated with Nothing.

```bash
# Ubuntu/Debian: sudo apt install python3-gi gir1.2-gtk-4.0 gir1.2-adw-1
git clone https://github.com/YTArmen/cmf-buds-linux.git && cd cmf-buds-linux && ./install.sh
```

Requires libadwaita ≥ 1.7. Pair the buds in system Bluetooth settings first. The app finds them by name.
