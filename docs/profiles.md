# Профили наушников

Программа (Linux) и приложение (Android) понимают наушники разных марок через **профили**.

## Как это устроено

Каждая марка «говорит» на своём языке команд. Язык состоит из двух частей:

1. **Кодек** — как упаковать команду в байты: начало и конец пакета, длина, контрольная сумма.
   Кодеки — это код. Они **встроены в программу** и обновляются только вместе с ней.
   Скачивать код из интернета небезопасно: подменённый файл запустил бы чужой код.
2. **Профиль** — какие команды есть у конкретных моделей: какие байты включают шумоподавление,
   как называются режимы, по каким именам узнать наушники. Это **просто данные (JSON)**,
   несколько килобайт. Профили лежат в папке `profiles/` этого репозитория. Программа сама
   скачивает нужный профиль, когда видит новые наушники.

Наушники без профиля всё равно видны: заряд показывается по стандарту Bluetooth
(если наушники его сообщают).

## Файлы

- `profiles/index.json` — список профилей: id, версия, имя файла, по каким названиям узнавать.
- `profiles/<id>.json` — сам профиль.

## Формат профиля

```json
{
  "id": "nothing",
  "version": 1,
  "name": "Nothing / CMF",
  "codec": "nothing",
  "match": { "names": ["CMF Buds", "Nothing Ear"] },
  "transport": { "type": "rfcomm", "uuid": "aeac4a03-dff5-498f-843a-34487cf133eb", "channel": 15 },
  "features": {
    "battery": { "read": "c007" },
    "noise": {
      "set": "f00f", "read": "c01e",
      "modes": [
        { "id": "off", "label": "Выкл", "payload": "010500" },
        { "id": "transparency", "label": "Прозрачность", "payload": "010700" },
        { "id": "anc", "label": "Шумоподавление", "payload": "010100" }
      ]
    }
  }
}
```

- `codec` — какой встроенный кодек использовать (`nothing`, `apple-aap`, `samsung`, `sony-v1`, `sony-v2`, `xiaomi`).
  Если программа не знает кодек, она предложит обновиться.
- `match.names` — начало названия наушников в Bluetooth (без учёта регистра).
- `features` — что умеют наушники. Чего нет в профиле, того нет в окне.
- Числа и байты пишутся шестнадцатеричной строкой (`"010500"`).

## Как добавить свою модель

1. Скопируйте похожий профиль, поменяйте `id`, `name`, `match.names`.
2. Поправьте команды (их можно подсмотреть в открытых проектах, например Gadgetbridge).
3. Добавьте строку в `profiles/index.json` и пришлите Pull Request.
